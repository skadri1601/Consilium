# Export Formats

Consilium supports multiple export formats for Golden Prompts, making it easy to use them with different AI coding assistants.

## Available Formats

### 1. Copy to Clipboard

The simplest way to use a Golden Prompt:

1. Click the **Copy** button (or press `Cmd/Ctrl + C`)
2. Paste into your AI coding assistant

**Best for:** Quick use, testing prompts, sharing with others

### 2. .cursorrules File

Export as a `.cursorrules` file for use with Cursor:

1. Click **Export as .cursorrules**
2. Save the file to your project root
3. Cursor will automatically use it for context

**Format:**
```
# Cursor Rules
# Generated by Consilium

[Your Golden Prompt content]
```

**Best for:** Cursor users, persistent project context

### 3. Markdown File

Export as a Markdown file with metadata:

1. Click **Export as Markdown**
2. Save the file anywhere
3. Use as documentation or import into other tools

**Format:**
```markdown
# Golden Prompt

[Your Golden Prompt content]

**Cost:** $0.0123
**Models Used:** gpt-4o-mini, claude-3-5-haiku-latest
```

**Best for:** Documentation, sharing, version control

## Using with Different Tools

### Cursor

1. Export as `.cursorrules`
2. Place in project root: `/your-project/.cursorrules`
3. Cursor automatically loads it
4. The prompt provides context for all AI interactions

**Tip:** Update the `.cursorrules` file when you refine your requirements.

### GitHub Copilot

1. Copy the Golden Prompt to clipboard
2. In VS Code, start a new chat with Copilot
3. Paste the prompt as context
4. Ask Copilot to implement based on the prompt

**Tip:** Use the prompt as a system message for better consistency.

### ChatGPT / Claude

1. Copy the Golden Prompt
2. Use it as:
   - A system prompt (if supported)
   - The first message in a conversation
   - Context in a follow-up message

**Tip:** Add "Based on this prompt, help me build..." before pasting.

### Custom AI Assistants

Golden Prompts are designed to be:
- **Self-contained**: Include all necessary context
- **Clear**: Explicit instructions and requirements
- **Complete**: Cover edge cases and error handling

You can use them with any AI assistant that accepts text prompts.

## Best Practices

### 1. Review Before Using

Always review the Golden Prompt before using it:
- Check that it matches your requirements
- Verify technical details are correct
- Add any project-specific context

### 2. Iterate and Refine

Golden Prompts are a starting point:
- Use them as a base
- Refine based on your specific needs
- Save improved versions for future use

### 3. Version Control

Consider saving Golden Prompts:
- In your project repository
- As documentation
- For team sharing

### 4. Combine with Project Context

Golden Prompts work best when combined with:
- Your existing codebase
- Project documentation
- Team conventions

## Examples

### Example 1: REST API

**Golden Prompt:**
```
Build a REST API using Node.js, Express, and PostgreSQL with the following features:
- User authentication with JWT tokens
- Password hashing with bcrypt
- Protected routes with middleware
- Input validation with Zod
- Error handling middleware
- CORS configuration
- Environment variable configuration
- Database migrations with Prisma
```

**Usage:** Export as `.cursorrules` for Cursor, or copy to Copilot chat.

### Example 2: React Dashboard

**Golden Prompt:**
```
Create a React dashboard with:
- TypeScript and Next.js 15
- Tailwind CSS for styling
- TanStack Query for data fetching
- Real-time updates with WebSockets
- Responsive design (mobile-first)
- Dark mode support
- Accessible components (ARIA labels)
```

**Usage:** Copy to clipboard and paste into ChatGPT/Claude for step-by-step implementation.

### Example 3: Database Schema

**Golden Prompt:**
```
Design a PostgreSQL database schema for an e-commerce platform:
- Users table with authentication fields
- Products table with categories and pricing
- Orders table with status tracking
- OrderItems junction table
- Proper indexes for performance
- Foreign key constraints
- Timestamps for audit trail
```

**Usage:** Export as Markdown for documentation, or use with database design tools.

## Troubleshooting

### Prompt is too long

If the prompt exceeds limits:
- Break into smaller, focused prompts
- Use multiple debates for different aspects
- Combine results manually

### Prompt doesn't work with my tool

Some tools have specific formatting requirements:
- Check the tool's documentation
- Adjust the prompt format if needed
- Add tool-specific instructions

### Need to modify the prompt

Golden Prompts are starting points:
- Edit them as needed
- Add project-specific details
- Remove irrelevant sections

## Advanced Usage

### Combining Multiple Prompts

For complex projects:
1. Create separate debates for different aspects
2. Export each as a separate file
3. Combine or reference them in your project

### Prompt Templates

Save common Golden Prompts as templates:
- Create a `prompts/` directory in your project
- Store `.cursorrules` or `.md` files
- Reference them when starting new features

### Team Sharing

Share Golden Prompts with your team:
- Commit to version control
- Document in project README
- Use for onboarding new developers
