THESE ARE NON-NEGOTIABLE. Violating any of these is a session failure:

- **Never push to GitHub directly** — provide git commands instead. No exceptions. Even if user says "push it", output the command for them to run.
- **Never add "Co-Authored-By" or "Generated by Claude Code"** to commits — the user explicitly prohibits this.
- **Before claiming work is complete**, run typecheck + tests for ALL changed packages. No "it should work" — prove it.
- **Billing code stays on a separate feature branch** — never on main.
- **Repository is PRIVATE** — do not reference MIT license, open-source, or public GitHub links in any code or UI.
- Remove/replace any "View on GitHub", "Open Source", "MIT License", or "Star on GitHub" CTAs with appropriate alternatives.
- **Never use sleep/timeout/retry as fixes** — solve root cause (see feedback memory).
